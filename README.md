## Implementation Stage
### WHAT IS DIGITAL IMPLEMENTATION?
Digital Implementation is the process of importing a gate-level netlist as well as the technology 
libraries and generating a physical design that meets power, performance and area (PPA) goals.

## Input Files Used for Physical Design\

| Input File | Definition and Use |
|---|---|
| Gate-Level Netlist (`.v`) | Contains the logic connectivity of the standard cells generated by the synthesis tool. |
| Design Constraints (`.sdc`) | Defines timing constraints, including clock periods, input/output delays, clock uncertainty, and timing exceptions. |
| Liberty Library (`.lib`) | Contains logical and timing information for standard cells and macros, including setup time, hold time, cell delay, and power characteristics. |
| Library Exchange Format (`.lef`) | Contains physical abstracts of standard cells and macros, including dimensions, pin locations, and obstruction information. |
| Technology LEF (`.lef`) | Defines physical routing layers, vias, layer properties, and relevant manufacturing design rules. |
| RC Extraction Technology File (`.qrcTech`) | Provides technology-specific information used by supported extraction tools to calculate interconnect resistance and capacitance. |

## Floorplanning the Design
1. Floorplanning is the process of defining the physical boundaries and initial organization of the design.
- Die area: Total area of the chip.
- Core area: Region allocated for implementing the main circuit.
- Utilization: Fraction of core area occupied by standard cells.
- Aspect ratio: Ratio of core width to core height.
- Pin placement: Assignment of physical locations to I/O pins.

## Power Planning
Power planning creates the network that distributes power and ground to the cells.
- PDN: Power Distribution Network.
- Power ring: Conductive structure distributing power around a region.
- Power straps: Wider conductors that distribute power across the core.
- IR drop: Supply-voltage loss due to resistance in the power network.
- Electromigration: Potential conductor degradation caused by excessive current density.

## Running Placement Optimization
Placement assigns legal physical locations to standard cells.
- Global placement: Optimizes approximate cell positions.
- Detailed placement: Legalizes and refines cell locations.
- Congestion: Competition for limited routing resources.
- Buffer insertion: Adds buffers to improve signal drive or timing.
- Cell sizing: Changes cell drive strength to improve implementation objectives.
  
1. Load the scan DEF file by running the following command:
   ```bash
   defIn core_netlist_def.scandef
   ```
2. Set the scan reordering mode by running the following command:
   ```bash
   set_db reorder_scan_comp_logic true
   ```
3. Run Placement optimization by running the followingcommand:
   ```bash
   place_opt_design
   ```

## Running Clock Tree Synthesis
Clock Tree Synthesis (CTS) builds the clock distribution network connecting the clock source to sequential elements.
- Clock skew: Difference in clock arrival times at relevant sequential elements.
- Clock latency: Time taken for the clock to reach a clock pin from its reference point.
- Clock buffers: Cells used to drive the clock network.
- Clock insertion delay: Delay introduced by the clock distribution path.

1. Generate the clock tree spec file constraints from the .sdc file by running the following command:
   ```bash
   create_ccopt_clock_tree_spec core.spec
   ```
2. Create a clock tree by running the following command:
   ```bash
   ccopt_design
   ```
3. Save Your Design as postCTSopt by entering:
   ```bash
   write_db postCTSopt
   ```

## Routing the Nets
Routing creates the physical interconnections between cells using metal wires and vias.
- Global routing: Plans approximate routes and allocates routing resources.
- Detailed routing: Creates the actual wire geometries and vias.
- Via: Conductive connection between metal layers.
- DRC: Design Rule Check for manufacturing geometry rules.
- Signal integrity: Evaluation of electrical effects such as coupling and crosstalk.

1. To Route the nets, choose **Route-NanoRoute-Route**

## Extraction and Timing Analysis
Parasitic extraction calculates the resistance and capacitance introduced by the physical interconnect.
- RC extraction: Estimates wire resistance and capacitance.
- SPEF: Standard Parasitic Exchange Format used to represent extracted parasitics.
- Coupling capacitance: Capacitance between neighboring conductors.
These parasitics are important for accurate post-route timing analysis.

1. Run RC Extraction on the routed design by selecting **Timig-Extract RC**\

## Running Physical Verification
Physical verification checks whether the layout satisfies manufacturing and connectivity requirements.
- DRC: Checks layout against applicable design rules.
- LVS: Layout Versus Schematic; checks whether extracted layout connectivity matches the reference netlist.
- Antenna checks: Check for potential manufacturing-related antenna-rule violations.
- Metal density checks: Verify applicable metal-density requirements

1. **Verifying Geometry**
   1. Choose **Check-Check DRC**

2. **Verifying Connectivity**
   1. Choose **Check-Check Connectivity**
